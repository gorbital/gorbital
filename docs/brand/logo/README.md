# gorbital — logo assets

Mark: **SLASH ORBIT** — a ring cut by the import-path slash, 34° tilt.

## Colours
- ink `#0B0C0A` · acid `#C6F24A` · paper `#F2F1EC` · slate `#16180F` · flare `#FF5C2B` · mute `#8E9285`

## Folders
- `svg/` — source vectors. Use these anywhere you can: mark variants, favicons, wordmark lockups.
- `png/` — mark at 1024/512/256, transparent and on solid grounds.
- `jpg/` — flattened 1024 marks for places that reject PNG/SVG.
- `favicon/` — 16/32/64/180/512 px + `favicon.svg`, `apple-touch-icon.png`, `site.webmanifest`, `head-snippet.html`.

## Rules
- Clear space on all sides = the ring's stroke width.
- Slash always tilts right at 34°. Never rotate, glow, gradient or bevel the mark.
- One accent colour inside the mark. Below 32px use the favicon files — the stroke and slash are thickened for small sizes.
- The wordmark is **Space Grotesk Bold, lowercase, -4% tracking**. Never "Gorbital" or "GORBITAL".

## Lockups
`svg/lockup-*.svg` reference Space Grotesk by name; install the font or convert the text to outlines before sending to a printer.
